Get the RoleMatch AI Chrome Extension

The RoleMatch AI Chrome extension makes it incredibly easy to scrape job descriptions directly from LinkedIn, Internshala, Naukri, or any other job portal. It instantly generates the clean .txt job scrape file required by the dashboard for analysis.

📥 Download Extension (v2)

How to install in Google Chrome:

  1. Download the rolematch-extension.zip file using the button above and extract (unzip) it to a folder on your computer.
  2. Open Google Chrome and navigate to chrome://extensions/ in your address bar.
  3. Toggle on Developer mode in the top right corner.
  4. Click the Load unpacked button in the top left.
  5. Select the folder where you extracted the extension. That's it!
